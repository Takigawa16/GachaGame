DROP YOUR CHARACTER ART HERE
============================
Filename must match the operator id, e.g.:

  ynna.png            -> Ynna (R, Fire, Sniper)
  ninette.png         -> Ninette (SR, Light, Defender)
  purp.png            -> Purp (SSR, Dark, Caster)
  solari.png          -> Solari (SSR, Light, Medic)
  angelina_ajimu.png  -> Angelina Ajimu (UR, Light, Sniper)

Full id list: get /api/config -> characters[].id

Recommended: transparent PNG, roughly 700x1200 (portrait), character centred
with the head in the upper third. The game already draws these in three crops
(VN scene, roster card, battle unit), so one well-framed file is enough.
Any missing file silently falls back to the built-in procedural art.
